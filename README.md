The purpose of this project is to find whether the winning candidates in recent elections have won due to a type of voting fraud coined as "differential invalidation" where votes are invalidated systematically to benefit a candidate. 

This project starts with the ElectionResultReader.py file, and creates CSV files by scraping data from the official Venezuelan election results website by parsing through the HTML code on each page that corresponds to a subregion of Venezuela. Then, it outputs a .csv file containing the election results, with columns including: regions and subregions (Estado, Municipio, Parroquia), candidates' count of votes in support, valid vote count, invalid vote count, total votes cast. The .csv files are included as election_data_2012.csv and election_data_2018.csv, for 2012 and 2018 respectively. 

Next, the csvComparer.py file is utilized to compare the two files to ensure columns were properly scraped, and that the data is, at the very least, similar between 2012 and 2018. Some discrepancies were found, but most were atributable to alterations in naming technique or redistricting that occured between elections. 

Finally, two .ipynb files each contain analysis of the elections in each year that was analyzed: Analysis2012.ipynb for the 2012 election, and Analysis2018.ipynb for the 2018 election. These both build out additional features for simplified analysis, support rate for a normalized (0-1) statistic for each candidates support, and validation rate, for a normalized (0-1) statistic for the rate at which votes were analyzed. Generalized linear models were constructed for each candidate between these statistics. However, the most relevant results were gleaned from VGAMs on winning candidates.

Findings in 2012 found signifigant correlations for all candidates, with most having increased validation rates with increased support for each candidate, aside from one (Radonski). Most candidates "benefitting" from vote invalidation, aside from the lead oppostion candidate, seems damning, however this is not within the scope of this project, as the focus is on the winner (Chavez). In vector-generalized linear modeling, it was found Chavez has a statistically signifigant NEGATIVE relationship between support rate and validation rates, indicating that he did not benefit from differential invalidation.

In 2018, different results were revealed. Maduro, the winning candidate, was found to have a statistically signifigant POSITIVE relationship between support rate and validation rate, with the validation rate increasing by approximately 1 percentage point with every 1 percentage point increase in Maduro's support rate. This is conclusive evidence for differential invalidation in support of Maduro.
